# Klarkommen – Mentale Stärke. Klare Richtung.

Offline-fähige Web-App zum Resilienz-Programm Klarkommen (Workshop-Version).

## Nutzen

Link zur App: `https://<github-name>.github.io/klarkommen-app/`
(Platzhalter – den echten Link hier eintragen, sobald GitHub Pages eingerichtet ist.)

Im Browser öffnen und „Zum Startbildschirm hinzufügen“ wählen. Danach in der App unter
*Einstellungen → Offline nutzen* auf **„Alles offline speichern“** tippen (am besten im WLAN),
damit Audios und Übungen auch ohne Internet laufen.
